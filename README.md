# HTML & CSS Task: Programming Languages Showcase

Welcome to the **HTML & CSS Task** repository! This project is a front-end HTML/CSS webpage displaying information and icons for various popular programming languages.

## 📌 Project Overview

This webpage showcases different programming languages including **Python**, **Java**, **C++**, **Rust**, and **Ruby**. It features custom CSS styling, flexbox layouts, card badges, and detailed descriptions for languages like Java, C++, and Ruby.

## 📁 Repository Structure

```
html-css-task/
└── css task/
    └── task.html    # Main HTML document containing structure and CSS styles
```

## 🚀 Getting Started

To view the task locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/shindevaishnvi/html-css-task.git
   ```
2. Navigate to the project directory:
   ```bash
   cd html-css-task/"css task"
   ```
3. Open `task.html` in any web browser.

## 🛠️ Built With

- **HTML5**: Page structure and content
- **CSS3**: Layouts, Flexbox, custom colors, and positioning
